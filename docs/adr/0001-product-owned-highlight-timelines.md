# Product-owned highlight timelines

Highlights are ordered on each product and resolved as a timeline rather than as
a separate campaign registry. The first active entry supplies the current
presentation, while a release promotion transitions from its temporary price to
a regular-price release and then disappears. Promotional prices are resolved
consistently across product surfaces and copied into the cart item when it is
added, so an existing draft order is not changed by a later date transition.

Recurring weekly promotions are also product-owned highlights. Each entry targets
one named weekday and is active for that weekday's local calendar day. They use
the same ordered first-active precedence as other highlights, including when
multiple weekly entries target the same weekday.
