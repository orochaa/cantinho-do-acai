# Domain Docs

Before exploring the app, read root `CONTEXT.md` and any ADR in `docs/adrs/`
that touches the work. If they do not exist, proceed silently.

This is a single-context repository. `CONTEXT.md` is the glossary; it contains
domain language, not implementation details. ADRs record durable, non-obvious
architectural decisions.

Use glossary terms in specs, tickets, code, and tests. Surface a conflict with
an ADR instead of silently overriding it.
